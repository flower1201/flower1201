## Stack & principles

```text
┌─────────────────────────────────────────────────────────┐
│  AI coding tools generate code / UI / sessions          │
│                      │                                  │
│                      ▼                                  │
│   PixelProof     RetryScope      RepoDiagram            │
│   visual proof   stuck loops     architecture map       │
│                      │                                  │
│                      ▼                                  │
│         Offline HTML / JSON / Mermaid                   │
│         Your machine · Your data · MIT                  │
└─────────────────────────────────────────────────────────┘
```

| Principle | Meaning |
|-----------|---------|
| **Local-first** | Runs on your machine; no account required |
| **No silent cloud** | Default path does not upload source / sessions |
| **Honest limits** | Pre-release · not on npm Registry yet |
| **Demoable** | Every repo ships `npm run demo` |

## Try any project in 60 seconds

```bash
# PixelProof — visual feedback for AI UIs
git clone https://github.com/flower1201/pixelproof.git
cd pixelproof && npm install && npm run build && npm run demo

# RetryScope — find where the agent got stuck
git clone https://github.com/flower1201/retryscope.git
cd retryscope && npm install && npm run demo

# RepoDiagram — map a private repo without uploading it
git clone https://github.com/flower1201/repodiagram.git
cd repodiagram && npm install && npm run demo
```
